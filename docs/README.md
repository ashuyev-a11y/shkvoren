# Документация ШКВОРЕНЬ — указатель и приоритет

## Порядок старшинства (что важнее при противоречии)

1. **`docs/decisions.md`** — зафиксированные решения. Старше всего остального.
2. **`tokens.json`** — все визуальные значения. Изменять только по явному указанию.
3. **`README (3).md`** (корень) — голос бренда и правила интерфейса.
4. **`AGENTS.md`** — правила работы агентов.
5. **`docs/data-model.md`**, **`docs/technical-spec.md`**, **`docs/product-spec.md`**,
   **`docs/implementation-plan.md`** — спецификации первой итерации (Qwen).
   **Устарели частично**, см. таблицу ниже. Переписываются задачами №2–№3.
6. **`schema.sql`** (корень) — схема Supabase. **Заморожена**: по решению 1
   (`decisions.md`) мастер-источник — Google-таблица, Supabase в MVP не используется.

## Источники данных

| Что | Где | Роль |
| --- | --- | --- |
| Каталог, цены, остатки | Google-таблица (сервисный аккаунт, только сервер) | Единственный мастер |
| Заказы | Лист «Заказы» той же таблицы | Запись при клике «Отправить в WhatsApp» |
| `Запчасти_с_ценами_рынка (2).xlsx` (корень) | Локальная копия | Снимок данных для разработки и проверки маппинга. **Не мастер** |

## Визуальные контракты

`docs/design/` — скриншоты экранов. **Сейчас пусто**, см. `docs/design/README.md`.
Задачи по вёрстке экранов заблокированы до их появления.
