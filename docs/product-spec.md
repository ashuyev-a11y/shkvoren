# Единое ТЗ продукта

## Цель

Создать интернет-магазин запчастей для автомобилей ГАЗ и УАЗ с продажей через сайт и WhatsApp. Магазин должен работать как витрина товаров с возможностью быстрого заказа через WhatsApp и администрирования через панель управления.

## Целевая аудитория

1. **Механики** - профессионалы, которым нужна конкретная деталь с номером
2. **Водители** - владельцы автомобилей, самостоятельно осуществляющие ремонт
3. **Автосервисы** - компании, покупающие запчасти оптом
4. **Администратор магазина** - сотрудник, управляющий каталогом и заказами

## Оптовая витрина

1. **Каталог товаров** с отображением наличия и цен
2. **Карточки товаров** с каталожным номером, названием, применимостью, фото
3. **Фильтрация** по марке автомобиля (ГАЗ/УАЗ)
4. **Поиск** по каталожным номерам и названиям
5. **Статус наличия** для каждого товара
6. **Цены** с отображением актуальной стоимости
7. **Кнопка заказа** через WhatsApp для каждого товара

## Поиск

1. **Основной поиск** на главной странице
2. **Поиск по каталожному номеру** (точное совпадение)
3. **Поиск по названию** (частичное совпадение)
4. **Поиск по кросс-номерам** (альтернативные номера)
5. **Быстрый доступ** к результатам поиска
6. **Подсветка** найденных номеров в результатах

## Каталог

1. **Структура каталога** по узлам автомобиля (двигатель, тормоза, КПП и т.д.)
2. **Список товаров** в виде строк (не плитка)
3. **Миниатюры** товаров 64px
4. **Название товара** жирным шрифтом
5. **Каталожный номер** моноширинным шрифтом
6. **Применимость** мелким серым текстом
7. **Цена** справа с акцентом
8. **Статус наличия** с цветовой индикацией
9. **Кнопка WhatsApp** для заказа

## Корзина

1. **Добавление товаров** в корзину
2. **Отображение** выбранных позиций
3. **Изменение количества** товаров
4. **Удаление** позиций из корзины
5. **Подсчет общей суммы** заказа
6. **Оформление заказа** через WhatsApp

## Заказ

1. **Формирование заказа** из корзины
2. **Отправка заказа** через WhatsApp
3. **Автоматическое формирование** текста сообщения с составом заказа
4. **Сохранение заказа** в системе
5. **Статус заказа** (новый, зарезервирован, оплачен, отправлен, выполнен, отменен)

## WhatsApp

1. **Интеграция** с WhatsApp для заказов
2. **Автоматическое формирование** сообщений с информацией о товарах
3. **Кнопки заказа** на всех уровнях (карточка товара, список, корзина)
4. **Формат сообщений** согласно голосу бренда

## Печатная накладная

1. **Генерация накладной** для каждого заказа
2. **Формат А4** для печати
3. **Информация о клиенте**
4. **Состав заказа** с ценами и количеством
5. **Итоговая сумма**
6. **Дата и номер заказа**

## Админка

1. **Управление товарами** (добавление, редактирование, удаление)
2. **Управление остатками**
3. **Управление ценами**
4. **Просмотр заказов**
5. **Изменение статусов заказов**
6. **Загрузка данных** из Excel
7. **Редактирование применимости**
8. **Управление фотографиями**

## Google Sheets

1. **Интеграция** с Google Sheets для импорта данных
2. **Автоматическая синхронизация** каталога
3. **Обновление цен** из таблиц
4. **Загрузка остатков** из таблиц

## Будущий AI-анализ цен

1. **Сбор данных** о ценах конкурентов
2. **Анализ рыночных цен**
3. **Рекомендации по ценообразованию**
4. **Автоматическое обновление цен**
5. **Уведомления о значительных изменениях цен**
