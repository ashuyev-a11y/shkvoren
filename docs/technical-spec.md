# Техническая спецификация ШКВОРЕНЬ

Архитектурный контракт. Всё, что здесь описано, — обязательно к исполнению.
Всё, чего здесь нет, исполнитель **возвращает вопросом**, а не додумывает (`AGENTS.md`).

Основана на `docs/decisions.md` (старше этого документа) и `docs/data-model.md`.

---

## 1. Архитектура

```
        браузер
           │  HTML/JSON, только публичные поля (PublicPart)
           ▼
   Next.js на Vercel  ───────────────►  Google Sheets API v4
   ├─ Server Components: витрина          (сервисный аккаунт,
   ├─ Route Handlers:   /api/*             ключ только на сервере)
   ├─ кэш чтения 3–5 мин
   └─ Client Components: корзина (Zustand + localStorage)
```

**Базы данных нет.** Единственное хранилище — Google-таблица (решение 1).
`schema.sql` в корне заморожен и в MVP не применяется.

### Что где выполняется

| Слой | Ответственность |
| --- | --- |
| Server Components | чтение каталога, фильтрация по марке, первый рендер списка |
| Route Handlers | поиск, создание заказа, сброс кэша, вход в админку |
| Client Components | корзина, степперы количества, поле телефона, сборка ссылки WhatsApp |

**Ключ сервисного аккаунта никогда не попадает в клиентский бандл.**
Обращения к Sheets API — только из Server Components и Route Handlers.

## 2. Стек

| Что | Решение | Почему именно так |
| --- | --- | --- |
| Фреймворк | Next.js 15, App Router | `AGENTS.md` |
| Язык | TypeScript, `strict: true` | `AGENTS.md` |
| Стили | Tailwind CSS v4 | `AGENTS.md` |

| Не используем | Причина |
| --- | --- |
| Prisma, Drizzle, любой ORM | нет БД |
| Supabase (в т.ч. Auth) | решения 1 и 6 |
| Redis | 278 позиций помещаются в память процесса |
| `pdf-lib`, `puppeteer`, серверный рендер PDF | печать через браузер |
| UI-библиотеки (MUI, shadcn, Radix) | своя дизайн-система, `tokens.json` |

## 5. Доступ к данным

### `lib/sheets.ts`

Две функции, больше ничего:

```ts
getValues(range: string): Promise<string[][]>       // чтение
appendRow(sheet: string, row: string[]): Promise<number> // дозапись, вернуть номер строки
```

Авторизация — JWT сервисного аккаунта.
Права: `https://www.googleapis.com/auth/spreadsheets`.

### `lib/parts.ts`

```ts
getParts(): Promise<{ parts: PublicPart[]; issues: SheetIssue[] }>
```

Порядок обработки — по `docs/data-model.md`:

1. прочитать лист целиком;
2. отбросить строку заголовков;
3. для каждой строки: `ID` (обязателен) → `title` → `price` → `qty`;
   отсутствие любого из них — `SheetIssue`, позиция **не попадает** в `parts`;
4. нормализовать `title` (trim), вычислить `articleKind`, `articleNorm`, `brands`;
5. отфильтровать марки: оставить позиции с `ГАЗ` или `УАЗ` и позиции с пустой
   применимостью (открытый вопрос №1);
6. сверить контрольные суммы, расхождение → `SheetIssue` уровня `warning`.

### Кэширование

```ts
unstable_cache(getParts, ['parts'], { revalidate: 240, tags: ['parts'] })
```

240 секунд = 4 минуты, середина интервала из решения 1.
Кнопка «Обновить сейчас» в админке вызывает `revalidateTag('parts')`.

### Отказ Sheets API

Витрина **не показывает пустой каталог** при ошибке чтения: отдаётся последний
успешный кэш и плашка «Данные могли устареть». Если кэша нет —
страница ошибки текстом по голосу бренда, без стектрейса.

## 6. Контракты API

Все ответы — `application/json`. Тексты ошибок — по голосу бренда,
на «вы», без восклицательных знаков.

### `GET /api/parts`

| Параметр | Значения | По умолчанию |
| --- | --- | --- |
| `brand` | `ГАЗ` \| `УАЗ` | все |
| `category` | значение из данных | все |
| `inStock` | `1` | выключено |
| `limit` | 1..200 | 50 |
| `offset` | ≥0 | 0 |

```json
{ "items": [ /* PublicPart */ ], "total": 262, "limit": 50, "offset": 0 }
```

### `GET /api/search?q=`

`q` — от 2 символов. Порядок результатов (`docs/data-model.md` §5):

1. точное совпадение `articleNorm`;
2. `articleNorm` начинается с запроса (от 4 знаков);
3. `articleNorm` содержит запрос (от 4 знаков);
4. триграммное совпадение по `title`.

```json
{ "items": [ /* PublicPart */ ], "total": 3, "q": "3501" }
```

Пустой результат — `items: []` и HTTP 200. Текст «ничего не найдено» рисует UI.

### `POST /api/orders`

```ts
// запрос
{ phone: string; items: { id: number; qty: number }[] }
```

Валидация:

| Поле | Правило | Ошибка |
| --- | --- | --- |
| `phone` | обязателен, 10–15 цифр после очистки (решение 2) | `Укажите телефон — без него мы не сможем с вами связаться.` |
| `items` | 1..100 позиций | `Добавьте хотя бы одну позицию.` |
| `items[].qty` | целое 1..`qty` позиции | `Столько нет в наличии.` |

**Цена берётся с сервера по `id`, а не из запроса.** Клиентская цена игнорируется.

```json
{ "orderNo": "ШКВ-0001", "total": 47500, "whatsappUrl": "https://wa.me/..." }
```

Порядок (решение 2, `docs/data-model.md` §8): запись в лист → затем ответ.
Ошибка записи → HTTP 502, ссылки WhatsApp в ответе нет.

### `POST /api/admin/login`

`{ password }` → cookie `shkv_admin`: `HttpOnly`, `Secure`, `SameSite=Lax`,
срок 7 дней, значение — HMAC-SHA256 от срока на `ADMIN_SESSION_SECRET`.
Сравнение пароля — `timingSafeEqual`.

### `POST /api/admin/refresh`

Требует cookie. `revalidateTag('parts')` → `{ ok: true, refreshedAt }`.

## 7. Поиск

Выполняется **в памяти** по кэшированному массиву: 278 позиций, полный проход
занимает доли миллисекунды. Postgres, `pg_trgm` и внешний поисковый движок
не нужны — прежняя редакция спецификации требовала их по инерции от `schema.sql`.

Триграммное сравнение по `title` — своя реализация в `lib/search.ts`
(коэффициент Дайса, порог 0.3). Внешняя зависимость не требуется.

## 8. WhatsApp

`lib/whatsapp.ts` собирает текст **строго по решению 12** — шаблон зафиксирован
и протестирован, изменять нельзя:

```
Здравствуйте! Хочу заказать по распродаже склада:
<номер> — <название>, <кол-во> шт x <цена> = <сумма>
...
Итого: <сумма>
Мой телефон: <телефон>
```

- строка `Мой телефон:` добавляется только при заполненном поле;
- `<номер>` — артикул; при его отсутствии строка начинается с названия;
- числа форматируются как на витрине (`17 500`);
- ссылка: `https://wa.me/${NEXT_PUBLIC_WHATSAPP_NUMBER}?text=${encodeURIComponent(text)}`;
- открывается `target="_blank" rel="noopener"`.

Номер заказа `ШКВ-NNNN` добавляется в текст первой строкой после записи в лист.

## 9. Дизайн-система в коде

### Генерация токенов

`scripts/generate-tokens.mjs` читает `tokens.json` и пишет `styles/tokens.css`:

```css
:root { --surface: #F3F2EE; --ink: #15171A; /* ... */ }
[data-theme="dark"] { --surface: #111315; /* ... */ }
```

Запускается в `predev` и `prebuild`. **`tokens.css` не редактируется руками**
и помечен в `.gitattributes` как генерируемый.

Tailwind v4 подключает те же переменные через `@theme`.
Никаких дублирующих значений в `tailwind.config` — единственный источник `tokens.json`.

### Обязательные правила вёрстки

Из `README (3).md`, проверяются на ревью:

- цена — `font-variant-numeric: tabular-nums`, пробел-разделитель тысяч, `₸`;
- артикул — моноширинный и копируемый;
- высота кнопок и строк списка — не меньше `space-12` (48px);
- `:focus-visible` — токен `focus-ring`, никогда не снимать;
- каталог — плотный список, не плитка;
- жёлтый `signal` — только заливка, никогда не текст на светлом;
- минимальный размер текста на мобильном — 16px.

### Шрифты

`next/font/google`: Unbounded 700/800, Onest 400/600/700, JetBrains Mono 600/700,
подмножество `cyrillic` + `latin`, `display: 'swap'`.

### Логотип

`design-system.json` ссылается на `shkvoren-mark.svg` и `shkvoren-mark-mono.svg`,
но поле `blobs` пусто — **файлов знака в репозитории нет**.
До их получения в шапке — вордмарк «ШКВОРЕНЬ» гарнитурой Unbounded 800.
Это осознанная временная мера, зафиксированная здесь, а не заглушка в коде.

## 11. Обязательные тесты

| Тест | Проверяет |
| --- | --- |
| Публичный ответ не содержит `cost`, `закупоч`, `market`, `рынк` | решение 5 |
| `articleNorm('53А170201002') === articleNorm('53A170201002')` | кириллица/латиница |
| Поиск `3501` находит позиции с `4693501070` | частичный номер |
| Строка без `ID` даёт `SheetIssue`, а не позицию без номера | `data-model.md` §3 |
| Позиция `ВАЗ` не попадает в публичный список | решение 7 |
| Позиция с пустой применимостью попадает | открытый вопрос №1 |
| Текст WhatsApp совпадает с решением 12 посимвольно | решение 12 |
| Цена 17500 форматируется как `17 500 ₸` | токены |
| Заказ с `qty` больше остатка отклоняется | §6 |

`scripts/check-sheet.mjs` — диагностика реальной таблицы: печатает контрольные
суммы, список `SheetIssue`, количество позиций по маркам. Запускается вручную
перед деплоем.

## 12. Вне MVP

Не проектировать и не закладывать «на будущее» в коде:
Kaspi/Kolesa/2GIS, XML-фиды, фото, кросс-номера, SEO-страницы на каждую деталь,
выгрузка прайса, AI-агент цен, тёмная тема, личные кабинеты, онлайн-оплата.

Данные для AI-агента (колонки R–AH) **читаются и сохраняются** в объект
`AdminPart`, но наружу не отдаются и в UI витрины не используются.
