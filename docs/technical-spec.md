# Техническая спецификация

## Next.js

1. **Версия**: Next.js 14 с App Router
2. **Рендеринг**: Server Side Rendering (SSR) и Static Site Generation (SSG) где возможно
3. **API Routes**: Встроенные API endpoints через pages/api
4. **Оптимизация**: Автоматическая оптимизация изображений
5. **Роутинг**: Файловая система роутинга

## TypeScript

1. **Строгая типизация** во всем проекте
2. **Интерфейсы** для всех компонентов и данных
3. **Типы** для API ответов
4. **Проверка типов** на этапе сборки

## Tailwind

1. **Версия**: Tailwind CSS v3+
2. **Конфигурация**: Кастомные токены из design system
3. **Цвета**: Только из tokens.json
4. **Типографика**: Только из tokens.json
5. **Отступы**: Только из tokens.json
6. **Радиусы**: Только из tokens.json

## Компоненты

1. **Button** - кнопки действий
2. **Badge** - бейджи статусов
3. **Card** - карточки товаров
4. **Search** - компонент поиска
5. **ProductList** - список товаров
6. **ProductItem** - элемент списка товаров
7. **Header** - шапка сайта
8. **Footer** - подвал сайта
9. **Cart** - компонент корзины
10. **OrderForm** - форма заказа
11. **WhatsAppButton** - кнопка заказа через WhatsApp

## API

1. **/api/products** - получение списка товаров
2. **/api/products/[id]** - получение информации о товаре
3. **/api/search** - поиск товаров
4. **/api/orders** - управление заказами
5. **/api/cart** - управление корзиной
6. **/api/whatsapp** - генерация сообщений WhatsApp

## Слой данных

1. **PostgreSQL** как основная база данных
2. **Supabase** как платформа для работы с PostgreSQL
3. **Prisma** как ORM (опционально)
4. **Кэширование** через Redis (опционально)
5. **Миграции** через инструменты Supabase

## Google Sheets

1. **Импорт данных** из Google Sheets в базу данных
2. **Автоматическая синхронизация** по расписанию
3. **Обработка ошибок** при импорте
4. **Логирование** операций импорта

## Поиск

1. **Full-text search** через PostgreSQL
2. **Поиск по каталожным номерам**
3. **Поиск по кросс-номерам**
4. **Поиск по названиям товаров**
5. **Триграммный поиск** для частичных совпадений

## Генерация накладной

1. **PDF генерация** через библиотеку pdf-lib или аналогичную
2. **Шаблон накладной** в соответствии с фирменным стилем
3. **Автоматическое формирование** при создании заказа
4. **Скачивание** накладной администратором

## WhatsApp

1. **Формирование URL** для отправки сообщений
2. **Шаблоны сообщений** согласно голосу бренда
3. **Кодирование текста** для URL
4. **Открытие WhatsApp** в новой вкладке/приложении

2. **Рекомендации по ценообразованию**
