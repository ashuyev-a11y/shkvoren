# Модель данных

## Используемая схема

Используется схема из файла `schema.sql` с дополнениями из Excel файла `Запчасти_с_ценами_рынка (2).xlsx`.

## Обязательные поля

### Таблица parts (товары)
1. **id** - UUID, первичный ключ
2. **sku** - Артикул (уникальный), текст, обязательно
3. **catalog_no** - Каталожный номер, текст, обязательно
4. **title** - Название товара, текст, обязательно
5. **unit_group** - Группа узлов (например, "Сцепление", "Тормоза"), текст, обязательно
6. **condition** - Состояние ("Новый"), текст, обязательно
7. **qty** - Количество на складе, число, обязательно
8. **price** - Цена продажи, число с двумя знаками после запятой, обязательно
9. **is_active** - Активность товара, булево, обязательно

### Таблица vehicle_models (модели автомобилей)
1. **id** - SERIAL, первичный ключ
2. **brand** - Марка ("ГАЗ" или "УАЗ"), текст, обязательно
3. **name** - Название модели, текст, обязательно

### Таблица part_fitment (применимость)
1. **part_id** - UUID, ссылка на parts.id, обязательно
2. **model_id** - INTEGER, ссылка на vehicle_models.id, обязательно

### Таблица orders (заказы)
1. **id** - UUID, первичный ключ
2. **channel** - Канал заказа, текст, обязательно
3. **status** - Статус заказа, текст, обязательно
4. **total** - Общая сумма, число с двумя знаками после запятой, обязательно

## Необязательные поля

### Таблица parts (товары)
1. **manufacturer** - Производитель, текст
2. **location** - Местоположение на складе, текст
3. **cost_price** - Закупочная цена, число с двумя знаками после запятой
4. **abc** - Категория ABC, символ ('A','B','C')
5. **description** - Описание товара, текст

### Таблица vehicle_models (модели автомобилей)
1. **aliases** - Алиасы модели, массив текста

### Таблица engines (двигатели)
1. **id** - SERIAL, первичный ключ
2. **name** - Название двигателя, текст
3. **aliases** - Алиасы двигателя, массив текста

### Таблица part_fitment (применимость)
1. **engine_id** - INTEGER, ссылка на engines.id (может быть NULL)

### Таблица part_cross (кросс-номера)
1. **part_id** - UUID, ссылка на parts.id
2. **cross_no** - Кросс-номер, текст

### Таблица part_photos (фотографии)
1. **id** - UUID, первичный ключ
2. **part_id** - UUID, ссылка на parts.id
3. **url** - URL фотографии, текст
4. **sort** - Порядок сортировки, число

### Таблица competitor_prices (цены конкурентов)
1. **id** - BIGSERIAL, первичный ключ
2. **part_id** - UUID, ссылка на parts.id
3. **source** - Источник ("kolesa","kaspi","other")
4. **price** - Цена конкурента, число с двумя знаками после запятой
5. **url** - URL страницы конкурента, текст

### Таблица channel_listings (публикации в каналах)
1. **part_id** - UUID, ссылка на parts.id
2. **channel** - Канал ("kaspi","kolesa","site","2gis")
3. **external_id** - Внешний ID
4. **status** - Статус публикации
5. **synced_at** - Дата синхронизации

### Таблица customers (клиенты)
1. **id** - UUID, первичный ключ
2. **kind** - Тип клиента ("retail","sto","fleet","gov","dealer")
3. **name** - Имя клиента, текст
4. **phone** - Телефон, текст
5. **bin_iin** - БИН/ИИН, текст
6. **city** - Город, текст
7. **discount** - Скидка, число с двумя знаками после запятой
8. **source** - Источник ("whatsapp","kaspi","kolesa","2gis","walk-in")

### Таблица inquiries (запросы)
1. **id** - BIGSERIAL, первичный ключ
2. **customer_id** - UUID, ссылка на customers.id
3. **channel** - Канал запроса, текст
4. **query_text** - Текст запроса, текст
5. **matched_part** - UUID, ссылка на parts.id
6. **in_stock** - Наличие на складе, булево

### Таблица order_items (позиции заказа)
1. **order_id** - UUID, ссылка на orders.id
2. **part_id** - UUID, ссылка на parts.id
3. **qty** - Количество, число
4. **price** - Цена, число с двумя знаками после запятой

## Идентификатор товара

UUID, генерируется автоматически при создании товара. Хранится в поле `id` таблицы `parts`.

## Артикулы и кросс-номера

### SKU (Stock Keeping Unit)
- Хранится в поле `sku` таблицы `parts`
- Уникальный идентификатор товара в системе учета
- Формат: G-XXXX для ГАЗ, U-XXXX для УАЗ

### Каталожный номер
- Хранится в поле `catalog_no` таблицы `parts`
- Номер, указанный на самой детали
- Может содержать буквы и цифры

### Кросс-номера
- Хранятся в таблице `part_cross`
- Связаны с товаром через `part_id`
- Один товар может иметь несколько кросс-номеров

## Применимость

Хранится в таблице `part_fitment` со связями:
- `part_id` - ссылка на товар
- `model_id` - ссылка на модель автомобиля
- `engine_id` - ссылка на двигатель (опционально)

## Закупочная цена

Хранится в поле `cost_price` таблицы `parts`. 
Необязательное поле, используется для расчета маржи.

## Цена реализации

Хранится в поле `price` таблицы `parts`.
Обязательное поле, используется для отображения на сайте и в заказах.

## Остаток

Хранится в поле `qty` таблицы `parts`.
Обязательное поле, целое число, не может быть отрицательным.

## Источники данных

1. **Excel файл** `Запчасти_с_ценами_рынка (2).xlsx` - первоначальные данные о товарах
2. **База данных PostgreSQL** - основное хранилище данных
3. **Google Sheets** - источник для регулярного обновления данных
4. **Парсеры** - будущий источник цен конкурентов
5. **WhatsApp** - источник заказов и запросов
6. **Сайт** - источник заказов через корзину
