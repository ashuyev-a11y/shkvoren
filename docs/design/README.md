## Как получить

1. Открыть артефакт: https://claude.ai/artifact/DjpwQP7n9UiigmYbXsyyKY
2. Включить Play на каждом артборде.
3. Снять скриншот на указанной ширине.
4. Положить сюда под именами из таблицы.

## Правила использования

- Скриншот — **визуальный контракт**: состав блоков, иерархия, порядок элементов.
- Скриншот **не является источником значений**: все цвета, шрифты, отступы и радиусы
  берутся из `tokens.json`, а не пипеткой с картинки.
- `.dc.html` из редактора дизайна в репозиторий не кладём и разметку из него не копируем —
  компоненты пишутся заново (решение зафиксировано в `docs/decisions.md`).
