## 1. Что это

Опт-витрина новых запчастей ГАЗ и УАЗ в Уральске. Один магазин, один
оператор, распродажа склада по себестоимости. Розницы нет, ценовой
уровень один (решение 0).

Путь покупателя:

```
каталог → поиск → корзина → телефон → заказ пишется в таблицу → WhatsApp
                                    ↘ печатный бланк A4
```

**Боевой адрес:** https://shkvoren-mu.vercel.app
**Админка:** https://shkvoren-mu.vercel.app/admin (пароль в `.env.local`)

## 2. Как устроено

| Слой | Чем сделан |
| --- | --- |
| Фронтенд | Next.js 15, App Router, React 19, TypeScript strict |
| Стили | Tailwind v4, цвета только через CSS-переменные из `tokens.json` |
| Состояние | Zustand + `persist` (корзина в `localStorage`) |
| Данные | Google-таблица через Sheets API, сервисный аккаунт, только сервер |
| Деплой | Vercel, продакшен из ветки `main` |

Базы данных нет. `schema.sql` в корне заморожен: по решению 1 мастер —
Google-таблица, Supabase в MVP не подключается.

Библиотека `googleapis` не используется: JWT RS256 подписывается через
`node:crypto`, запросы идут обычным `fetch` (`lib/sheets.ts`).

**Деплой только через API.** CLI `vercel deploy --prod` на hobby-плане
при подключённом git возвращает `BLOCKED`. Рабочий способ:

```js
POST https://api.vercel.com/v13/deployments?teamId=<team>&forceNew=1
{ name, project, target: 'production',
  gitSource: { type: 'github', repoId: 1376770968, ref: 'main' } }
```

Токен: `C:/Users/Владелец/AppData/Roaming/xdg.data/com.vercel.cli/auth.json`,
поле `token`.

**Запись переменных.** Прямой `POST /v10/projects/.../env` отдаёт
`Not authorized`. Работает только через CLI, значение подаётся на stdin:

```bash
cat значение.txt | vercel env add ИМЯ production --force
```

Через аргумент `--value` кириллица и длинный ключ ломаются.

**Проверка значений.** `vercel env pull` на зашифрованных переменных
отдаёт пустоту, API с `decrypt=true` — длину шифротекста, а не значения.
Единственная честная проверка — прогон `check-sheet.mjs`.

**Два аккаунта в `gh`.** Активным бывает `flowers2account`, и тогда
`git push` падает с «Repository not found». Лечится:

### Два бага после запуска

**`db2f2ef` — телефон и зависание каталога**

`lib/sheets.ts`: запись заказа переведена с `USER_ENTERED` на `RAW`.
Google принимал телефон с плюсом за формулу и писал в лист `#ERROR!`
вместо контакта покупателя.

`components/ProductRow.tsx`: `prefetch={false}` у ссылки на карточку.
Каталог показывает все 271 позицию одним списком, и Next.js подгружал
карточку каждой видимой строки — сотни запросов подряд, страница
переставала отвечать.

**`0373342` — страница заказа висела на «Загружаем заказ…»**

`lib/cart.ts`: флаг `hydrated` ставился через `useCart.setState()`
внутри `onRehydrateStorage`. Колбэк zustand выполняется **до** слияния
восстановленного состояния, и записанное значение затиралось обратно
в `false`. Корзина не выходила из состояния загрузки никогда.

Исправлено мутацией переданного состояния: `if (state) state.hydrated = true`.
Добавлена запасная ветка на случай, когда `state` приходит пустым —
битый JSON в `localStorage` или приватное окно: там флаг поднимается
отложенно через `queueMicrotask`, иначе страница заказа не открывалась
бы вовсе.

`tests/cart.test.mjs` — пять тестов на все четыре состояния хранилища.

## 7. Правила, которые нельзя нарушать

Порядок старшинства документов (`docs/README.md`):

```
decisions.md > tokens.json > README (3).md > AGENTS.md > спеки
```

Спека правится под решение, а не наоборот.

- **Данные не выдумываются.** Цены, названия, артикулы, применимость,
  адрес продавца — только из таблицы или переменных окружения. Пустая
  переменная означает отсутствие строки, а не подставленный образец.
- **`README (3).md` и `tokens.json`** не изменяются без явного указания.
- **Цвета только через токены**, иначе гейт `hex-color` роняет сборку.
- **Секреты не попадают в репозиторий** — только в переменные Vercel
  и keyring `gh`.
- **Заглушек и `TODO` не остаётся** — ESLint `no-warning-comments`.
- **Голос бренда:** коротко, на «вы», без эмодзи и восклицаний.
  Цены в формате `17 500 ₸`.
- Каждая задача завершается коммитом на русском с перечнем сделанного
  и отменённого.
- Временные скрипты пишутся в корне проекта и удаляются после работы.

### Ключевые решения и их причины

| Решение | Почему так |
| --- | --- |
| Ключ позиции — колонка `ID`, не артикул | артикула нет у 91 позиции, три дубля |
| Копия таблицы через `IMPORTRANGE` отвергнута | `ID` не переживёт вставку строк в оригинале: `ID 47` укажет на соседний товар, и цена в бланке будет чужой, молча |
| Цена заказа берётся с сервера по `id` | клиентское значение игнорируется |
| Порядок «запись в лист → ссылка WhatsApp» | заказ, не записанный в таблицу, не существует; при отказе Google отдаём 502 без ссылки |
| Адреса `/order/:number/print` нет намеренно | номера последовательны, перебором открывался бы чужой заказ с телефоном |
| Админка только читает | источник — таблица; `/admin/sync` не делается, синхронизации нет, есть сброс кэша |
| Печать — HTML + `@media print` | номер заказа на бланке не печатается: он присваивается листом при записи, а бланк печатается до отправки |
| Фильтр марок на сервере | девять чужих не уходят в браузер; семь без применимости остаются |

### Технические мелочи, о которые уже спотыкались

- Node в режиме strip-only TS ломается на parameter property и
  `server-only` — чистую логику держать отдельно от серверной.
- Windows/Git предупреждает `LF will be replaced by CRLF` — это норма.
- `styles/tokens.css` генерируется из `tokens.json` на `prebuild`,
  руками не правится.
- `.dc.html` из редактора дизайна в репозиторий не кладётся, разметка
  из него не копируется.
