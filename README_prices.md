# Сравнение цен с поставщиками

Скрипт сопоставляет наш каталог (`data/our/`) с прайсами поставщиков
(`data/suppliers/`) и собирает `result/price_comparison_<дата>.xlsx`.
К сайту отношения не имеет, в сборку не входит.

## Запуск

```bash
pip install -r requirements.txt   # один раз
python compare.py
```

В конце скрипт печатает, сколько товаров сопоставлено, сколько на проверку
и сколько не найдено.

## Обновить прайс

Положить новый файл в `data/suppliers/` и удалить старый.
В `config/suppliers.yaml` путь задан шаблоном (`Прайс Росзапчасть*.xlsx`),
поэтому дата в имени файла правки конфига не требует. Если шаблону
подходит несколько файлов, берётся последний по имени, и скрипт об этом
напишет. Свой каталог — так же, в `data/our/`.

Курс рубля — `config/settings.yaml` → `rates`. Обновлять вместе с прайсами.

## Добавить поставщика

1. Положить файл в `data/suppliers/`.
2. Дописать блок в `config/suppliers.yaml` (образец — закомментированный
   Сервис-Штамп):
   - `file` — путь или шаблон со `*`;
   - `currency` — `KZT` или `RUB` (для другой валюты добавить курс в `settings.yaml`);
   - `sheets` — `all` или список листов;
   - `header_row` — номер строки заголовков как в Excel или `auto`
     (найдёт сам по названиям колонок);
   - `columns` — как называются колонки в шапке прайса. Обязательны
     `article` и `price`, остальные (`brand`, `name`, `unit`, `stock`,
     `code`, `oem`) — если есть.
3. Новых производителей с другим написанием дописать в `config/brands.yaml`.

Код при этом не меняется. Форматы: `.xlsx`, `.xls`, `.xlsb`.

## Как сопоставляется

| Способ | В расчёте |
| --- | --- |
| Артикул совпал, производитель ГАЗ/УАЗ | да |
| Артикул совпал без точек, тире и кода модификации (наш `4691701164` = `469-1701164` = `0469-00-1701164-00`), производитель ГАЗ/УАЗ | да |
| Артикул совпал, другой производитель (аналог) | нет (`count_analogs: true` — да) |
| Артикул совпал, производитель не указан или указан город | нет, на проверку |
| Похожее название | нет, только подсказка на листе «Не найдено» |

- Артикул нормализуется: верхний регистр, без пробелов, дефисов, точек,
  слэшей; кириллица, похожая на латиницу (А/A, Х/X), приводится к латинице.
  Короче 5 знаков не сопоставляется.
- Цены переводятся в тенге по курсу из `settings.yaml`.
- Наша цена — розничная («Цена продажи»). Цены поставщиков — оптовые,
  ориентир; доставка и растаможка не добавляются. Цены без остатка учитываются.
- У поставщика берётся минимальная цена по артикулу, все варианты — на листе «Детали».
- Если цен три и больше, цена дальше от медианы больше чем в 3 раза
  исключается как вероятная ошибка. При двух ценах, отличающихся
  настолько, обе остаются и помечаются на проверку.
- Единица «компл», «упак» — цена идёт в расчёт, строка помечается
  на проверку: за штуку ли цена, не понять.

## Листы результата

- **Итоги** — насколько наша розница выше оптовых цен поставщиков:
  медиана и средняя наценка, в целом и по каждому поставщику.
- **Сводка** — все наши товары: у скольких поставщиков найден, мин/макс/
  средняя/медиана, у кого минимум, наценка нашей цены к средней и медиане. Красный — мы
  дороже средней, зелёный — дешевле.
- **Детали** — все совпадения с исходными данными поставщика и способом совпадения.
- **На проверку** — сомнительные совпадения и выбросы, с причиной.
- **Не найдено** — товары без совпадений, с подсказками по названию.
- **Артикулы** — наши артикулы, записанные без точек и тире, в том виде,
  как их пишут поставщики (`53121701306` → `53-12-1701306`). По такому
  артикулу находит поиск. Таблицу скрипт не меняет — это подсказка для правки.
- **Параметры** — дата, курс, какие файлы читались.
